# Data Availability

The raw source datasets are **not included in this public portfolio repository**.

This project was built from course-provided project data for a NovaTech Solutions scenario. The public portfolio intentionally publishes only derived screenshots, dashboard exports, metric definitions, and case-study documentation.

## Source domains represented

- CRM Deals
- Marketing Campaigns
- Support Tickets

## Key public results documented in this repository

- Marketing population: 2,240 records
- Support population: 3,000 tickets
- CRM: 499 raw records and 496 governed distinct opportunities in the Sales Pipeline view

If adapting this project pattern to production data, the recommended next steps would include source-system lineage, formal data contracts, refresh SLAs, metric ownership, and row-/column-level access controls.
